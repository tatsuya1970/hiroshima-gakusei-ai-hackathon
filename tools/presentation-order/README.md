# 発表順抽選アプリ

各チームがスマホからチーム名を入力し、会場の大画面でルーレット演出とともに発表順を決める。
依存パッケージなし（Node.js 18 以上だけで動く）。

```
スマホ（各チーム） ──チーム名──▶ 会場PC（server.mjs） ──リアルタイム表示──▶ 大画面（/host）
```

## 当日の流れ

1. 会場PCでサーバーを起動する

   ```
   cd tools/presentation-order
   node server.mjs
   ```

2. 表示された **大画面用URL**（`http://localhost:3000/host?key=...`）をPCのブラウザで開き、プロジェクターに映す。`F` キーで全画面
3. 各チームが大画面のQRコードを読み取り、スマホでチーム名を入力する。入力されるたびに大画面の枠が埋まる
4. 8チームそろうと「抽選スタート」ボタンが押せるようになる。押すとルーレットが回り、1番から順に決まっていく（約30秒）
5. 最後に発表順のスライドと同じ体裁の結果画面になり、各スマホにも「あなたのチームは○番目」が表示される
6. 結果画面の右下「PowerPointで保存」で、同じ体裁のスライドを `発表順_YYYYMMDD.pptx` としてPCに保存できる（大画面・公開大画面のどちらからでも。図形とテキストで作るので PowerPoint で編集できる。ライブラリを CDN から読むのでネット接続が必要）

大画面用URLの `key` を知らないと抽選の開始やリセットはできない。スマホ用URLには `key` が付かない。

**公開大画面** — `/screen`（例：`https://xxxx.trycloudflare.com/screen`）を開くと、大画面と同じ表示（エントリー状況・ルーレット演出・結果）を誰でも見られる。URLは起動時の表示と ⚙ メニューに出る。

- 8チームそろうと公開大画面にも「抽選スタート」ボタンが出て、押すと全画面で抽選が始まる（二重に押されても抽選は1回だけ）
- 右上の「クリア」ボタンで、エントリーと結果をすべて消して最初からにできる
- ⚠️ どちらも key 不要なので、公開大画面のURLを知っている人は誰でも押せる。URLの配り先に注意する

**デバッグ用** — スマホ用URLに `?debug` を付ける（例：`https://xxxx.trycloudflare.com/?debug`）と、送ったチームを端末に記憶しないので、同じスマホやPCから何件でも送れる。エントリー後の「続けて別のチームを送る」で次のチームを入力する。

## 管理メニュー（大画面の左上の ⚙）

| 操作 | 用途 |
|---|---|
| 代理エントリー | スマホを使えないチームの名前を運営が入れる |
| エントリーの削除 | ロビー画面でチーム枠にマウスを乗せると出る × |
| 演出をスキップ（`S`） | ルーレットを飛ばしてすぐ結果を出す |
| 同じチームでもう一度抽選する | リハーサル後や、やり直しが必要なとき |
| 全リセット | エントリーもすべて消して最初から |

## 設定

`server.mjs` の先頭の `CONFIG` を書き換える。

- `capacity` — チーム数（既定 8）。環境変数 `TEAMS` でも指定できる
- `time` — 結果画面の左上・右上に出る発表開始時刻
- `note` — 結果画面の説明文

環境変数：`PORT`（既定 3000）、`HOST_KEY`（大画面用URLのkeyを固定したいとき）、`PUBLIC_URL`（トンネル利用時。下記）

エントリー内容は `state.json` に保存されるので、サーバーを再起動しても消えない（git管理外）。

## スマホがつながらないとき

スマホとPCが **同じWi-Fi** にいる必要がある。会場Wi-Fiが端末どうしの通信を遮断している（ゲスト用Wi-Fiに多い）と、QRを読んでも開けない。

- **対策1：PCのモバイルホットスポット** — Windowsの「モバイルホットスポット」をONにし、各チームにそのWi-Fiへつないでもらう
- **対策2：トンネルで公開URLを作る** — [cloudflared](https://developers.cloudflare.com/cloudflare-one/connections/connect-networks/downloads/)（アカウント不要）を使う

  ```
  cloudflared tunnel --url http://localhost:3000
  ```

  表示された `https://xxxx.trycloudflare.com` を使い、`PUBLIC_URL` を付けてサーバーを起動し直すと、QRがそのURLになる。

  ```powershell
  $env:PUBLIC_URL = "https://xxxx.trycloudflare.com"
  node server.mjs
  ```

  または大画面を `https://xxxx.trycloudflare.com/host?key=...` で開けば、QRは自動でそのURLになる。

  一時トンネルはリアルタイム通知（SSE）を通さないので、自動で1秒ごとの問い合わせに切り替わる（反映まで最大1秒ほど遅れる）。トンネルのURLは cloudflared を起動し直すたびに変わる。

QRコードの描画には CDN（jsdelivr）を使う。PCがインターネットにつながっていないときはQRの代わりにURLの文字が出るので、それを入力してもらう。

大画面のURL表示をクリックすると、候補のURL（有線とWi-Fiなど）を切り替えられる。
