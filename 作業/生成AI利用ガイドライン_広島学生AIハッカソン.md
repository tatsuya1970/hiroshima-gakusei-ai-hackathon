# 生成AI・開発サービス 利用ガイドライン

**広島学生AIハッカソン**（2026年9月19日）／主催: HiBiS DX・ITトレンド研究部会　最終改定: 2026年8月7日

> **参加規約をわかりやすくまとめたものです。**正式なルールは参加規約によります。年齢の条件は2026年7月30日時点のもので、予告なく変わります。

## 1. 使う道具（中学生から大学生まで全員同じ）

| 何に使う | 使うもの | 年齢 |
|---|---|---|
| **AIサービス**（コード・画像） | **ChatGPT** ／ **Gemini** | 13歳以上（18歳未満は保護者の同意） |
| **AIコーディングツール** | **Codex だけ** | ChatGPTと同じ |
| **公開（デプロイ）** | **Netlify Drop** ／ **GitHub Pages** ／ **ChatGPT Sites** | 13歳以上 |

年齢で使える道具に差が出ないよう揃えています。

- **Codex は「モデルの名前」ではなく、OpenAIのコーディングエージェントという製品の名前です。**
- **エディタ（VS Code など）は自由に使えます。**制限がかかるのは、そこに入れるAI機能のほうです。

## 2. 主な使えないもの

- **Claude・GitHub Copilot・Cursor・Google Antigravity・Windsurf**
- **Vercel など、上に挙げた以外の公開先**
- **AIモデルのAPI**（OpenAI API・Gemini API など）
- **音楽・音声の生成AI**（Suno・ElevenLabs・Gemini の音楽生成）

BGM・効果音は**フリー素材**を使ってください。

## 3. APIのこと

**使えないのは「AIモデルのAPI」だけで、APIが全部ダメなわけではありません。**

- **地図・天気・オープンデータなど、AI以外の公開APIは使えます。**各APIの利用規約を守ってください。
- **作品そのものにAI機能（作品の中のAIチャットなど）は入れられません。**AIでつくったイラストを**素材として入れるのはOK**です。

## 4. アカウントの準備

- **当日までに**用意してください。運営は用意も貸与もしません。
- **18歳未満の方は、保護者の同意を得たうえでアカウントをつくってください。**
- **他人（家族・友人・先生・メンター）のアカウントは使えません。年齢を偽っての作成も禁止です。**
- **学校のアカウント**を校外で使ってよいかは学校の規則によります。**事前に確認してください。**

## 5. やってはいけないこと

- **個人情報をAIに入力すること**（本名・学校名・住所・電話番号・顔写真など）。**一度入力したものは取り消せません。**
- **保護者の同意なく、人のクレジットカードなど支払情報を登録すること。**
- **事前につくったコードや作品を持ち込むこと**（公開のライブラリ・テンプレートはOK）。
- **実在の人物、アニメやゲームのキャラクター、企業のロゴを生成すること。**

借りた素材は**利用条件を確認して**使ってください。作品の権利は**つくったチームのもの**です。

## 6. 無料版で最後まで走りきるコツ

- **チーム全員が ChatGPT と Gemini の両方を持つ。**片方が止まっても、もう一方や別のメンバーの端末に切り替えられます。2〜3名チームなら実質4〜6アカウント分が保険になります。
- **作品全体のコードを毎回貼り直さず、直したい部分だけをAIに渡す。**
- **同じ指示を何度も送り直さない。**書き直してから1回送るほうが早く着きます。
