# 生成AI・開発サービス 利用ガイドライン

**広島学生AIハッカソン**（2026年9月19日）／主催: HiBiS DX・ITトレンド研究部会　最終改定: 2026年8月7日

> **参加規約をわかりやすくまとめたものです。**正式なルールは参加規約によります。年齢の条件は2026年7月30日時点のもので、予告なく変わります。

## 1. 使う道具（中学生から大学生まで全員同じ）

| 何に使う | 使うもの | 年齢 |
|---|---|---|
| **AI**（コード・画像） | **ChatGPT** ／ **Gemini** | 13歳以上（18歳未満は保護者の同意） |
| **AIコーディングツール** | **Codex だけ** | ChatGPTと同じ |
| **公開（デプロイ）** | **Netlify Drop** ／ **GitHub Pages** ／ **ChatGPT Sites** | 13歳以上 |

**すべて無料・クレジットカード不要です。**年齢で使える道具に差が出ないよう揃えています。使ったAIの種類は審査に関係しません。

- **Codex は「モデルの名前」ではなく、OpenAIのコーディングエージェントという製品の名前です。**ChatGPTのアカウントの範囲で使えるので、追加の登録もカードも要りません。
- **Codex は希望者だけの上級オプション。**使う人は**当日までに自宅で導入と有効化を済ませて**きてください（当日その場でのインストールは不可）。使わなくても完成・公開できます。
- **エディタ（VS Code など）は自由に使えます。**制限がかかるのは、そこに入れるAI機能のほうです。
- **揃えるのはAIについてだけです。**公開のライブラリ・素材（Leaflet、国土地理院タイル、Google Fonts など）は自由に使えます。

## 2. 使えないもの

- **Claude・GitHub Copilot・Cursor・Google Antigravity・Windsurf**
- **Vercel など、上に挙げた以外の公開先**（年齢の条件を満たさないものがあります。Vercel は16歳以上）
- **AIモデルのAPI**（OpenAI API・Gemini API など）… Gemini API は**18歳以上限定**で、18歳未満が使うサービスへの組み込みも禁止。OpenAI API はカード登録が必要です
- **音楽・音声の生成AI**（Suno・ElevenLabs・Gemini の音楽生成）… 18歳以上限定のものがあり中高生が使えないため、**大学生チームも含めて全員使いません**

BGM・効果音は**フリー素材**を使い、作品ページの最後に出典を書いてください。**音がなくても審査には影響しません。**

## 3. APIのこと

**使えないのは「AIモデルのAPI」だけで、APIが全部ダメなわけではありません。**

- **地図・天気・オープンデータなど、AI以外の公開APIは使えます。**各APIの利用規約を守ってください。APIキーの取得が必要でも構いません。
- **ログインして使うものはAPIではありません。**ChatGPT・Gemini・Codex は安心して使ってください。「**APIキーを取得してください**」と出るものが、AIのAPIです。
- **AIは年齢の条件を気にせず、APIを使うコードを提案してきます。**言われるまま進めず、迷ったらメンターに聞いてください。
- **作品そのものにAI機能（作品の中のAIチャットなど）は入れられません。**AIでつくったイラストを**素材として入れるのはOK**です。

## 4. アカウントの準備

- **ChatGPTとGeminiの両方を、チーム全員が各自で、当日までに**用意してください。運営は用意も貸与もしません。
- **18歳未満の方は、保護者と一緒に。**参加そのものにも保護者の同意が必要です。
- **他人（家族・友人・先生・メンター）のアカウントは使えません。年齢を偽っての作成も禁止です。**
- **学校のアカウント**を校外で使ってよいかは学校の規則によります。**事前に先生に確認してください。**

## 5. やってはいけないこと

- **個人情報をAIに入力すること**（本名・学校名・住所・電話番号・顔写真など）。**一度入力したものは取り消せません。**テストに名前や住所が必要なときは、**架空のもの**（例: 山田太郎、広島市中区1-1-1）を使ってください。
- **保護者の同意なく、人のクレジットカードなど支払情報を登録すること。**
- **事前につくったコードや作品を持ち込むこと**（公開のライブラリ・テンプレートはOK）。
- **実在の人物、アニメやゲームのキャラクター、企業のロゴを生成すること。**

借りた素材は**利用条件を確認し、作品ページの最後に出典を書いて**ください。作品の権利は**つくったチームのもの**です。**AIを使ったことは隠さず、発表でどのAIを使ったかを言ってください。**

## 6. 無料版で最後まで走りきるコツ

- **チーム全員が ChatGPT と Gemini の両方を持つ。**片方が止まっても、もう一方や別のメンバーの端末に切り替えられます。2〜3名チームなら実質4〜6アカウント分が保険になります。
- **作品全体のコードを毎回貼り直さず、直したい部分だけをAIに渡す。**
- **同じ指示を何度も送り直さない。**書き直してから1回送るほうが早く着きます。

## 7. ルールを守れていなかったら

**いきなり失格になることはありません。**まず声をかけて直してもらい、**直していただければ、そのまま審査の対象です。**審査の対象外になるのは、**注意しても直さなかった場合**と、**悪質だと判断した場合**（違反と知りながら続けた／隠そうとした／年齢を偽った など）だけです。
