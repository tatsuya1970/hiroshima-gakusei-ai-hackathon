**広島学生AIハッカソン**（2026年9月19日）
主催: HiBiS DX・ITトレンド研究部会
制定: 2026年7月30日 ／ 最終改定: 2026年8月7日（「APIの見分け方」を改め、使えないのはAIモデルのAPIであってAI以外の公開APIは使えることを明記。作品内にAI機能を入れられないことを追記。違反時の措置を参加規約の改正に合わせ「まず注意・是正、従わない場合と悪質な場合のみ審査の対象外」に統一。参加規約の改定に合わせ、使用ツールの確認・検査に関する記載と、課金が不要である旨の記載を削除）

> 利用規約は予告なく変更されるため、**運営は内容を保証しません。参加前に必ず各自で最新の規約をご確認ください。**

## 1. 5つの大原則

1. **アカウントは各自で事前に準備してください。** 運営は当日アカウントを用意しません。運営やメンターのアカウントを貸すこともしません（ほとんどのサービスでアカウントの共有は規約違反です）。
2. **ChatGPTとGeminiの両方を、チーム全員がそれぞれ自分のアカウントで用意してください。** 無料版には使用量の上限があり、**チームで1つでは足りません**。片方が上限に達したら、もう一方に切り替えて開発を続けます。2〜3名のチームなら、実質4〜6アカウント分の枠が保険になります。
3. **上限に達したら、もう一方のAIや別のメンバーの端末に切り替えて開発を続けてください**（→ 第4項）。なお、**保護者の同意を得ずに保護者その他の第三者のクレジットカード等を登録することは禁止です**（参加規約 第11条9号）。
4. **13歳未満の方は参加できません。18歳未満の方は、保護者と一緒にアカウントを作ってください。** 多くのサービスは18歳未満の利用に保護者の同意を求めています。**18歳未満の方は、参加そのものについても保護者の同意が必要です**（参加規約 第2条3項）。
5. **個人情報をAIに入力しないでください**（→ 第5項）。**各サービスの利用規約と年齢条件を守ってください。**

### 募集要項を守らなかったときは

もし違反が見つかった場合は、**まず運営・メンターから声をかけ、直してもらいます。直していただければ、そのまま審査の対象です。うっかり違反しても、いきなり審査の対象外になることはありません。**

**審査の対象外となるのは、注意しても直さなかった場合と、悪質だと判断した場合だけ**です（参加規約 第5条3項）。信頼を前提にした運用ですので、ご協力をお願いします。

### 学校のアカウント（教育機関向けプラン）を使う場合

学校が契約している **Google Workspace for Education** などのアカウントでAIを使う場合、**校外のイベントで使ってよいかは学校の規則によります。**

- **事前に学校の先生に確認してください。**
- 学校が認めない場合は、**個人の無料アカウント**を用意してください。
- **運営から学校へ問い合わせや調整を行うことはしません**（参加規約 第2条4項）。

## 2. 大会公式ツール（全区分共通）

**本大会は、中学生から大学生まで全員が同じ道具で競います。**下の公式ツールだけで、作品の完成から公開まで到達できます。わからなければメンターに聞いてください。

> **使用できるAIは、OpenAI（ChatGPT・Codex）と Google（Gemini）が提供するものに限ります。APIキーの取得が必要な利用（OpenAI API・Gemini API 等）は含みません。**
>
> モデル名（GPT-5.6、Gemini 3 など）ではなく**提供元**で決めているのは、モデル名が頻繁に変わるためです。**「OpenAIかGoogleのサービスに、自分のアカウントでログインして使う」**と覚えてください。
>
> **この決まりは用途を問いません。コードを書かせるだけでなく、画像をつくるのにも使えます。**ChatGPT や Gemini の**画像生成機能で、作品に使うイラスト・アイコン・背景をつくってOK**です（→ 第6項の注意もお読みください）。
>
> **ただし、音楽・音声の生成は使いません**（→ 下の「音を使いたいときは」）。

| 用途 | 大会公式ツール | 年齢条件 |
|---|---|---|
| **AI（コードを書く）** | **ChatGPT（GPT）** ／ **Gemini**<br>※どちらも**Canvas**でプレビューまで完結します | ChatGPT: 13歳以上（18歳未満は保護者の同意が必要）<br>Gemini: 13歳以上（13〜17歳は保護機能が自動で有効） |
| **作品の公開（デプロイ）** | **Netlify Drop**（ドラッグ&ドロップ・初心者の本線）<br>**GitHub Pages**（コミット履歴が残る）<br>**ChatGPT Sites**（ベータ版） | Netlify: 13歳以上<br>GitHub: 13歳以上<br>ChatGPT Sites: ChatGPTアカウントの条件と同じ |
| **地図・データ** | OpenStreetMap + Leaflet ／ 国土地理院タイル ／ PLATEAU ／ Open-Meteo ／ e-Stat | アカウント不要 |

**すべて無料・クレジットカード不要です。**

**なぜ全区分で道具を揃えたのか**: 区分ごとに使えるツールを変えると、最優秀賞1チームを道具のちがう相手同士で争うことになります。道具を揃えれば、**道具の差ではなく発想と実装で競う**ことができます。あわせて、**使用したAIツールの種類・高機能さ・有料か無料かは、審査に考慮しません。**

### 上級オプション（希望者のみ・全区分で利用可）

**当日までに自宅で導入と有効化を済ませてきた人だけ**が使えます。**当日その場でのインストールは認めません**（1時間以上かかり、開発時間がなくなります）。

**エディタ（VS Code など）そのものは自由に使えます。**エディタはAIモデルでもホスティングサービスでもないため、大会の制限はかかりません。制限がかかるのは、**そこに入れるAI機能のほう**です。

| 上級オプション | 年齢条件 | 備考 |
|---|---|---|
| **Codex**（OpenAIのコーディングエージェント。デスクトップアプリ／CLI／VS Code拡張） | 13歳以上 | **提供元がOpenAI**で、ChatGPTアカウントの範囲で使えるため、追加登録もカードも不要。※無料プランでの利用可否は変動するため、**当日までにご自身で確認してください** |
| **Netlify Functions / Netlify Blobs**（サーバー機能） | 13歳以上 | カード不要。**無料枠は「使い切ったら止まるだけ」で課金は発生しません**。経験者チーム向け |

- **Codex は「モデルの名前」ではなく「製品の名前」です。**（2021〜2023年に同名のAIモデルがありましたが、まったくの別物です。）中で動くのはOpenAIのモデルなので、**モデルを選んでも大会のルールから外れることはありません。**
- 無料枠を使い切った場合は、ChatGPT／GeminiのCanvasに戻って開発を続けてください。
- **⚠️ GitHub Copilot は使えません。** 提供元がGitHubで、OpenAI・Google のどちらでもないためです。加えて **Copilot Free ではモデルを選べず（自動選択のみ）、どのモデルが動いたか本人にも分からない**という事情もあります。
- **⚠️ VS Code の「BYOK（自分のAPIキーを使う）」も使えません。** 自分で取得したAPIキーを登録してモデルを追加する機能で、**APIの直接利用にあたります。**追加したモデルは通常のモデルと同じ選択欄に並ぶため、気づきにくいのが要注意です。
- **Cursor・Google Antigravity・Windsurf・Cline・Roo Code・Continue なども同じ理由で使えません。**
- **エディタそのもの（VS Code など）は自由に使えます。**制限がかかるのは、そこに入れるAI機能のほうです。

## 3. 使わないもの

公式ツールで完結できるため、次のサービスは本大会では使いません。

| サービス | 使わない理由 |
|---|---|
| **Claude**（claude.ai） | **18歳以上限定で、保護者の同意があっても利用できません。** 会話の内容から未成年と判断されるとアカウントが停止される仕組みがあります |
| **GitHub Copilot** | **提供元がGitHub**で、OpenAI・Google のどちらでもありません。さらに Copilot Free は**モデルを選べず（自動選択のみ）、どのモデルが動いたか本人にも分かりません** |
| **Cursor** | 18歳以上。提供元も OpenAI・Google ではありません |
| **Google Antigravity** | **18歳未満は利用できません**（公式FAQに「At the moment, Antigravity is unavailable to under-18 users.」と明記） |
| **Windsurf・Devin その他のAIコーディングツール** | 使えるAIコーディングツールは **Codex だけ**です（参加規約 第5条3項） |
| **Vercel** | 16歳以上（中学生が使えません） |
| **Replit** | 規約の記載が矛盾しており、中高生の利用可否がはっきりしません |
| **Firebase・Google Cloud・AWS・Google Maps** | クレジットカードの登録が必須。**規約に年齢条項がなくても「使える」という意味ではありません**（契約する権能の表明を求められます） |
| **AIモデルのAPI**（OpenAI API・**Gemini API**・Anthropic API 等） | **Gemini API は18歳以上限定**で、さらに**18歳未満が利用するサービスへの組み込みも禁止**されています（Gemini API 追加利用規約「Age Requirements」に "You must be 18 years of age or older to use the APIs. You also will not use the Services as part of a website, application, or other service … that is directed towards or is likely to be accessed by individuals under the age of 18." と明記）。**OpenAI API は年齢制限自体はありません**（13歳以上・18歳未満は保護者の許可）が、**利用にクレジットカードの登録が必須**です。**ログインして使うこと（ChatGPT・Gemini・Codex）と、APIキーを取得して呼び出すことは別物**で、後者は使えません（参加規約 第5条3項） |
| **ElevenLabs**（音声生成） | **18歳以上限定**で、**保護者の同意による例外もありません**（規約1条(a)「If you are under 18 years of age…you may not use our Services」）。加えて**18歳未満の音声データのアップロードも禁止**されています |
| **Suno**（音楽生成） | 年齢は**13歳以上**で条件自体は満たしますが、**提供元が OpenAI・Google ではない**ため使えません |
| **Gemini の音楽生成機能**（Lyria） | **18歳以上限定**です（Google公式ヘルプに明記）。提供元の条件は満たしますが、**中高生が使えず区分によって差が出る**ため、本大会では全区分で使いません |
| **Cloudflare（Workers/KV/D1）・Supabase** | 規約に年齢条項が見あたらないため使いません |

- **上の表にないAIモデル・ホスティングサービスも使えません。**申告すれば使えるという運用ではなく、**OpenAI（ChatGPT・Codex）と Google（Gemini）／Netlify・GitHub Pages・ChatGPT Sites のみ**です。使ってしまった場合は、**気づいた時点で公式ツールに切り替えてください。切り替えていただければ、そのまま審査の対象です**（参加規約 第5条3項）。**判断に迷う場合**は、運営またはメンターにご相談ください。
- **13歳未満の方は、ほとんどの生成AIサービスを利用できません。本イベントの参加対象は13歳以上の中学生からです。**

### 音（BGM・効果音・ナレーション）を使いたいときは

**音楽・音声を生成するAIは、本大会では使いません。**

| なぜ使えないのか | |
|---|---|
| **ElevenLabs（音声）** | **18歳以上限定**。保護者の同意があっても使えません |
| **Suno（音楽）** | 13歳以上で年齢は満たしますが、**提供元が OpenAI・Google ではありません** |
| **Gemini の音楽生成（Lyria）** | 提供元の条件は満たしますが、**18歳以上限定**です。中高生が使えず区分によって差が出るため、**大学生チームも含めて全員使いません** |

**BGMや効果音がほしいときは、アカウント登録の要らない公開のフリー素材を使ってください。**利用条件（商用可・クレジット表記の要否など）を確認し、**作品ページの末尾に出典を書いて**ください。ライブラリと同じ扱いなので、登録画面が出ないものは自由に使えます。

**なお、音がなくても審査には一切影響しません。**審査基準は「作品が動くこと」です。**4時間で音まで作り込む余裕はまずありません**ので、まずは動くものを完成させることを優先してください。

### APIの見分け方（覚えておいてほしいこと）

**使えないのは「AIモデルのAPI」です。APIぜんぶが禁止ではありません。**

| | 使える？ |
|---|---|
| **AIモデルのAPI**（OpenAI API・Gemini API・Anthropic API 等） | ❌ **使えません**（参加規約 第5条3項） |
| **AI以外の公開API・データ**（地図、天気、時刻表、自治体のオープンデータ 等） | ⭕ **無料で使えて、クレジットカードの登録が要らないなら使えます。** APIキーの取得が必要でも構いません |
| **クレジットカードの登録を求めるサービス**（提供元は問いません） | ❌ **登録しないでください**（参加規約 第11条9号） |

**運営が、みなさんの使っているサービスの規約まで確認することはできません。**だからこそ、自分で見分けられるようにしておいてください。

- **AIは年齢条件を気にせず、AIのAPIを使うコードを提案してきます。**「このAPIキーをここに入れて」と言われても、そのまま進めないでください。
- **迷ったらメンターに声をかけてください。**別のやり方をご案内します。
- **ログインして使うものはAPIではありません。**ChatGPT・Gemini の画面はもちろん、**Codex（ChatGPTアカウントの範囲で使えるコーディング機能）**のように、追加のキー登録なしにログインだけで使えるものは大丈夫です。**安心して使ってください。**
- 公式ツール表（→ 第2項）の **Open-Meteo（天気）・国土地理院タイル・PLATEAU・e-Stat** は、どれもアカウント登録もキーも不要です。**まずはここから探してみてください。**

### 作品の中にAI機能は入れられません

AIモデルのAPIが使えないため、**提出する作品が、動いている最中にAIを呼び出すこと（作品内のAIチャット機能など）はできません。**

- **AIは「作品をつくるための道具」であって、「作品に組み込む部品」ではありません。**
- ただし、**AIでつくったイラスト・アイコン・背景などを、素材として作品に入れることはできます。**
- 「AIハッカソン」という名前ですが、**評価されるのはAIを使ってその場で何を作り上げたか**です。作品自体にAI機能があるかどうかは審査に一切影響しません（参加規約 第6条2項）。

## 4. 無料プランで最後まで走りきるコツ

**無料プランには使用量（トークン）の上限があります。**上限に達すると、しばらく使えなくなったり、性能の低い簡易モードに切り替わったりします。開発の途中でAIが止まると、そこで手が止まってしまいます。工夫をしてください。例えば次のような方法があります。

| コツ | なぜ効くか |
|---|---|
| **チーム全員が ChatGPT と Gemini の両方のアカウントを持つ** | 片方が上限に達しても、**もう一方のAI**や**別のメンバーの端末**に切り替えて続けられます。2〜3名チームなら実質4〜6アカウント分が保険になります |
| **作品全体のコードを毎回貼り直さず、直したい部分だけをAIに渡す** | 渡す量が減れば、消費が大きく減ります。「この関数だけ直して」と範囲を指定してください |
| **同じ指示を何度も送り直さない** | やり直しは消費が二重にかかります。うまくいかないときは、**指示を具体的に書き直してから**1回送るほうが早く着きます |

## 5. 個人情報を入力しない

**AIツールに入れてはいけないもの**

- 自分や他人の**本名・学校名・住所・電話番号・メールアドレス**
- **顔写真**、他人が写った写真
- 家族・友人・先生の情報
- パスワード、クレジットカード番号

**理由**: 入力した内容がAIの学習や品質改善に使われる設定になっている場合があります。一度入力したものは取り消せません。

**作品のテストに名前や住所が必要なときは、架空のもの（例: 山田太郎、広島市中区1-1-1）を使ってください。**

## 6. AIが作ったものの取り扱い

- AIが出したコード・画像・音楽にも、第三者の権利が関係することがあります（参加規約 第8条4項）。
- **実在の人物・アニメやゲームのキャラクター・企業のロゴを生成しないでください。**
- 発表のときは、**どのAIツールを使ったかを言ってください。**「AIを使ったことを隠す」ことが問題であり、AIを使うこと自体は推奨です。

## 7. 規約違反がわかったときの運営の対応

段階的に対応します。**うっかり間違えた場合に、いきなり失格になることはありません。**

**運営から「どのAIを使っているか」を確認して回ることはしません。**下の対応は、たまたま運営の目に触れた場合や、あとから判明した場合の扱いです。

| 状況 | 運営の対応 |
|---|---|
| 当日、運営やメンターが気づき、**その場で切り替えてもらえた**場合 | 別の方法に切り替えてもらって終わりです。**ペナルティはありません。** |
| 年齢条件に合わないサービスや公式ツール以外を使っていた場合 | そのサービスの使用をやめてもらい、公式ツールで作り直します。**時間内でできる範囲で運営とメンターが手伝います。** |
| **注意を受けても是正せず、そのまま提出された**場合 | **審査の対象外**とします（参加規約 第5条3項）。 |
| 提出後や発表後に判明した場合 | もう直せないため、**その場では何も求めません。**審査の対象外とするのは、**悪質だと判断した場合だけ**です（参加規約 第5条3項）。 |
| 悪質な場合（**違反と知りながら続けた**／違反を隠そうとした／年齢を偽る／他人の個人情報を入力／他人のアカウントを使用／第三者の権利を明らかに侵害） | 参加規約 第12条により、審査対象からの除外・参加の取消を行います。受賞後に判明した場合は第7条3項により受賞を取り消します。 |
| サービス側からアカウント停止などの措置を受けた場合 | **運営では解除できません。**各サービスの窓口へご自身で対応してください。 |

### 運営として注意すべき点

1. **募集開始前と開催1週間前（9/12頃）に、上表を再確認すること。** 特に ChatGPT は2025年9月に年齢確認を強化しており、変更頻度が高い。**ChatGPT Sites はベータのため、リハーサルでの動作検証と9/12の再確認を必須とする。**
2. **無料版の使用量上限が大会設計の急所。** ChatGPT無料版の高性能モデルは5時間あたり10メッセージ程度という情報があり、4時間の開発には足りない。**Gemini の高速モード（Flash）がほぼ無制限**である点が無料開催の生命線。**ChatGPTとGeminiの両方を公式ツールに入れた判断が最大の保険**であり、どちらか1つに絞ってはいけない。
3. **アカウントは当日会場で一斉に新規作成させないこと**（同一IPからの大量アカウント作成はレート制限の対象になり得る。通常利用の同時アクセス自体は問題にならない）。当日朝は軽い動作確認で十分。実リスクは帯域（モデルDL・npm install）の方。
4. **Next.js / React**: Next.jsは `output: 'export'` で静的化すればNetlify Dropに載るが、`npm install` で会場Wi-Fiが飽和し、本線のCanvasが使えなくなるため勧めない。「Reactが使いたいだけ」なら**CDNで単一HTML**（react/react-dom UMD ＋ babel-standalone）を案内する。
5. **中学生にVercelを案内してはいけない**（16歳以上）。LP・チラシ・当日スライドで「Vercelでデプロイ」と書かないこと。
6. デプロイ先を **Netlify Drop / GitHub Pages** に寄せると、当日の手順を運営側で1本に統一できる。当日マニュアルはこの2つで作る。
7. 参加規約 第2条・第5条は本ガイドラインに合わせて改定済み（2026-08-01）。
