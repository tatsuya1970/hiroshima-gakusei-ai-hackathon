# 広島学生AIハッカソン 参加規約

制定日: 2026年8月4日 ／ 最終改定: 2026年8月6日（AIモデルの確認方法・学校プランの扱い・無料プランでの工夫を追加、定員を25人前後に修正）
主催: HiBiS DX・ITトレンド研究部会（以下「主催者」）

本規約は、主催者が開催する「広島学生AIハッカソン」（以下「本イベント」）への参加に関する条件を定めるものです。参加申込をもって、本規約に同意したものとみなします。

---

## 第1条（イベント概要）

1. 名称: 広島学生AIハッカソン
2. 日時: 2026年9月19日（土）11:00〜17:00（受付10:30〜）
3. 会場: イノベーション・ハブ・ひろしまCamps（広島市）
4. 参加費: 無料（会場までの交通費、昼食代、通信費等は参加者の自己負担とします）

## 第2条（参加資格）

1. 本イベントに参加できるのは、**広島県内に所在する学校に在籍する学生**であって、次のいずれかの区分に該当し、**開催日時点で13歳以上**の方とします。
   - **13歳以上の中学生**
   - 高校生
   - 大学生・高専生・専門学校生
   - **13歳未満の方は参加できません。** 本イベントで使用する生成AIサービス・開発サービスの多くが13歳以上を利用条件としているためです（第3項）。中学1年生であっても、開催日時点で13歳に達していない場合は参加できません。
   - 小学生、大学院生、および学生でない方は対象外とします。
   - **在籍する学校の所在地により判断します。**広島県外に所在する学校に在籍している方は、広島県内にお住まいであっても対象外となります。
2. **18歳未満の方の参加には、保護者の同意を必要とします。** 同意の確認は**参加チームの決定後**に行い、対象となる方へ個別にご案内します（申込時には保護者の氏名・連絡先を取得しません）。
3. 参加者は開発に使用するサービスのアカウントを**各自で事前に準備**するものとします。主催者はアカウントを用意せず、主催者・メンターのアカウントを貸与しません。
4. **学校が契約する教育機関向けプラン**のアカウントを使用する場合は、**当該学校の規則・許可に従う**ものとします。校外のイベントでの利用可否は学校によって異なるため、参加者自身が事前に学校へ確認してください。主催者は学校との調整・確認を行いません。

## 第3条（参加形式・チーム）

1. 参加は**2名または3名のチーム単位**とし、申込もチーム単位で行うものとします。1名（個人）での参加はできません。
2. チームは**同一区分の学生のみ**で構成するものとします（例: 中学生は中学生どうし）。区分をまたぐ混成チームは認めません。同一区分内であれば、学年・学校が異なっていても構いません。
3. 定員は**25人前後**とします。会場の設営可能な席数に基づく人数です。
4. **応募が定員を超えた場合は、主催者が参加チームを決定します。**決定にあたっては、参加者の年齢（中学生・高校生・大学生等の区分）および学校のバランスを考慮し、特定の区分・学校に偏らないよう調整します。
5. 前項の決定はチーム単位で行うため、決定したチームの人数により、参加人数が定員を若干上回りまたは下回ることがあります。

## 第4条（申込）

1. 申込は主催者所定の方法（申込フォーム）により行うものとします。
2. 申込内容に虚偽があった場合、主催者は参加をお断りすることがあります。
3. 募集期間の終了後、応募が定員を超えた場合は前条第4項により参加チームを決定し、結果（参加可否）を申込を行ったすべてのチームの代表者のメールアドレスへ通知します。**選考の方法・結果に関する問い合わせには応じられません。**
4. キャンセルする場合は、速やかに主催者へ連絡するものとします。キャンセルにより空きが出た場合、参加とならなかったチームから繰り上げることがあります。

## 第5条（開発ルール）

1. 開発テーマは**当日発表**します。
2. 開発は**当日、会場でゼロから**行うものとし、事前に作成したコード・成果物の持ち込みは禁止します（一般に公開されているライブラリ・ツール・テンプレートの利用は可）。
   - 公開されているテンプレート・スターターキットの複製（クローン）は認めます。ただし、**完成済みのアプリケーションを複製し、内容を差し替えたにとどまるもの**は、本項の事前作成物とみなすことがあります。
3. **AIの活用を前提**とします。使用するAIモデルやホスティングツールは、中学生から大学生まで全区分で同一とします。AIモデルは **GPT・Gemini**、公開に使うホスティングサービスは **Netlify・GitHub Pages・ChatGPT Sites** です。
   - これは、サービスごとに利用可能年齢が異なるため、**参加者の年齢によって使える道具に差が出ることを避け、道具の差ではなく発想と実装で競う**ためです。
   - **使用できるAIは、OpenAI（ChatGPT・Codex）と Google（Gemini）が提供するものに限ります。APIキーの取得が必要な利用（OpenAI API・Gemini API 等）は含みません。** モデル名ではなく提供元で定めるのは、各社のモデル名が随時変更されるためです。
   - **本号は用途を問わず適用します。**コードの作成に限らず、**画像の生成も、OpenAI・Google が提供するもの（ChatGPT・Gemini の画像生成機能等）であれば使用できます。**作品に使用した生成物の取り扱いは第8条および利用ガイドラインによります。
   - **ただし、音楽・音声の生成は、全区分において使用しないものとします。** Gemini の音楽生成機能は**18歳以上**に限られており、区分によって使える道具に差が生じるためです。BGM・効果音等が必要な場合は、アカウント登録を要しない公開の素材を利用してください。
   - APIを使用できないのは、APIには各社の開発者向け規約が別に適用され、**Gemini API は18歳以上に限られるほか、18歳未満が利用するサービスへの組み込みも禁止**されているためです。**「APIキーの取得」または「クレジットカードの登録」を求める画面が表示された場合は、その時点で作業を止めてください。**
   - 前号により、**GitHub Copilot、Cursor、Google Antigravity、Windsurf 等のAIコーディングツールは使用できません。** これらは提供元が OpenAI・Google ではなく、また使用されるモデルを参加者が特定できない場合があるためです。**エディタ（VS Code 等）そのものは、AIモデルではないため自由に使用できます。**
   - **主催者は、参加者が使用したAIモデル・ホスティングサービスを確認・検査しません。** 参加者は、申込フォームにおいて**「使用するAIモデルなど、本イベントの募集要項（本規約および利用ガイドライン）を守ります」**の確認事項に同意するものとし、遵守は参加者の申告と責任に基づくものとします。
   - **募集要項に定める事項に違反したことが判明した場合は、当該チームを審査の対象外とします。**受賞後に判明した場合は、第7条第3項により受賞を取り消すことがあります。
4. 成果物は、**インターネット上にデプロイ（公開）した作品のURL**とし、主催者が指定する期限までに提出するものとします。デプロイはNetlify・GitHub Pages・ChatGPT Sites のいずれかを使用してください。
5. 参加者は、生成AIサービスに**自己または第三者の個人情報を入力してはなりません**（詳細は利用ガイドライン）。
6. 開発機材（ノートPC等）は参加者が持参してください。
7. **無料プランで参加するチームは、開発の途中でAIが使えなくなる事態を防ぐため、工夫を行ってください。**例えば次のような方法があります。
    - **チーム全員が、ChatGPTとGeminiの両方のアカウントを各自で用意する。** 片方が上限に達しても、もう一方のAI、または別のメンバーの端末に切り替えて開発を続けられます。
    - **作品全体のコードを毎回貼り直さず、直したい部分だけをAIに渡す。**
    - **同じ指示を何度も送り直さない。**
    - 主催者は無料の範囲で作品を完成できるよう開発テーマと進め方を設計します。**上限に達しても有料プランへ課金する必要はありません**（詳細は利用ガイドライン）。

## 第6条（発表・審査）

1. 発表は、提出されたURLの作品をスクリーンに映し、**実際に動かしながら**行います。**発表でのスライドの使用は禁止します。**
2. 審査基準は次の3項目とし、審査員の総合評価によります（配点はありません）。
   - **テーマ適合性**（開発テーマに沿った作品であること。事前の作り込みは評価せず、その場で作り上げるものを評価します）
   - **実装度**（作品が動くことを重視。アイデアのみは評価しません。**使用技術の目新しさや外部サービスとの連携数ではなく、その場で動くところまで到達したかを評価します**）
   - **チャレンジ精神**（知的好奇心と探求心。独創的な方法で問題を解決しようとする姿勢を重視します。**全チームが同一の大会公式ツール（第5条第3項）で開発するため、限られた道具の中でどう工夫したかを評価します**）
3. 発表のうまさは審査に考慮せず、審査は動く作品の内容のみで行います。
4. 事前に作り込んだと主催者が判断した作品は、審査対象外とすることがあります。**判断の際は、当日のメンターによる開発状況の確認、および（GitHubを使用した場合は）リポジトリのコミット履歴等の記録を参照することがあります。**
5. **審査結果に対する異議は受け付けません**。

## 第7条（賞）

1. 最優秀賞: 3万円分のAmazonギフト券（1チーム）
2. オーディエンス賞: 別途定める賞品
3. 不正行為（本規約違反を含む）が判明した場合、受賞後であっても受賞を取り消すことがあります。

## 第8条（知的財産権・成果物の取り扱い）

1. 成果物の著作権その他の知的財産権は、**制作した参加者（チーム）に帰属**します。
2. 前項にかかわらず、主催者は、本イベントの記録・広報の目的（Webサイト・SNS・報道対応・活動報告等）に限り、**作品名・作品概要・スクリーンショット・発表の様子を無償で使用**できるものとします。
3. 本イベントの発表は公開の場で行われるため、**秘密保持（NDA）は行いません**。秘匿したいアイデア・情報は持ち込まないでください。
4. 参加者は、第三者の知的財産権その他の権利（画像・音楽・フォント・コード等のライセンスを含む）を侵害してはなりません。第三者との紛争が生じた場合、参加者自身の責任と費用で解決するものとします。
5. チーム内における権利の配分は、チーム内の取り決めによるものとします。

## 第9条（肖像・広報）

1. 主催者は、本イベント中に参加者の写真・動画を撮影し、主催者およびHiBiSのWebサイト・SNS・広報物・報道機関への提供に使用することがあります。
2. 未成年者の肖像の使用については、保護者の同意を確認します。確認は**参加チームの決定後**に、第2条第2項の同意とあわせて行います。

## 第10条（個人情報）

1. 申込時に取得した個人情報は、本イベントの運営・連絡・安全管理の目的にのみ使用します。
2. 法令に基づく場合を除き、本人（未成年者の場合は保護者）の同意なく第三者に提供しません。

## 第11条（禁止事項）

参加者は、次の行為をしてはなりません。

1. 事前に作成したコード・成果物の持ち込み（第5条第2項）
2. 他の参加者・運営者・会場への迷惑行為、ハラスメント行為
3. 会場設備・備品の無断使用や損壊
4. 法令または公序良俗に反する行為、およびそのおそれのある作品の制作
5. 他チームの開発の妨害、成果物の盗用
6. 第5条第3項に定めるAIモデル・ホスティングサービス**以外の使用**、年齢条件を満たさないサービスの利用、および年齢を偽ってのアカウント作成
7. 他人（家族・友人・先生・メンター等を含む）のアカウントを使用しての開発
8. 生成AIサービスへの第三者の個人情報の入力
9. **保護者の同意を得ずに、保護者その他の第三者のクレジットカード等の支払情報を外部サービスに登録すること**
10. その他、主催者が不適切と判断する行為

## 第12条（参加の取消）

1. 主催者は、本規約に違反した参加者またはチームに対し、参加の取消・退場・審査対象からの除外等の措置をとることができます。

## 第13条（免責）

1. 主催者は、会場内での事故・傷病・持ち物の紛失・盗難について、主催者の故意または重大な過失による場合を除き、責任を負いません。持ち物は各自で管理してください。
2. 通信環境・AIツール・外部サービスの障害等により開発・提出・発表に支障が生じた場合でも、主催者は責任を負いません。可能な範囲で運営上の配慮を行います。
3. 参加者間または参加者と第三者との間で生じたトラブルは、当事者間で解決するものとします。

## 第14条（イベントの変更・中止）

1. 主催者は、天災、感染症の流行、会場の都合その他やむを得ない事情により、本イベントの内容変更・延期・中止を行うことがあります。
2. 変更・中止の場合は、申込時の連絡先およびWebサイト等で速やかに告知します。
3. 変更・中止により参加者に生じた損害（交通費等を含む）について、主催者は責任を負いません。

## 第15条（規約の変更）

主催者は、必要に応じて本規約を変更することがあります。変更後の規約は、Webサイト等での掲載をもって効力を生じます。

## 第16条（お問い合わせ）

本イベント・本規約に関するお問い合わせは、主催者（HiBiS DX・ITトレンド研究部会）までご連絡ください。
